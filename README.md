# 🚀 Meu Portfólio Pessoal

Este é o repositório do meu **Portfólio Pessoal**, desenvolvido com **React** e **Next.js**. O objetivo deste projeto é apresentar minhas habilidades, projetos, experiência e formas de contato de maneira moderna, rápida e responsiva.

---

## 🛠️ Tecnologias Utilizadas

- **React** & **Next.js** (App Router)
- **TypeScript**
- **Tailwind CSS** _(ou a biblioteca de estilos usada no projeto)_
- **Geist Font** (`next/font`)

---

## 💻 Como Rodar o Projeto Localmente

### Pré-requisitos

Certifique-se de ter o [Node.js](https://nodejs.org/) (versão 18+ recomendada) e o gerenciador de pacotes de sua preferência instalados.

### 1. Clonar o repositório

```bash
git clone [https://github.com/seu-usuario/seu-repositorio.git](https://github.com/seu-usuario/seu-repositorio.git)
cd seu-repositorio

2. Instalar as dependências

npm install
# ou
yarn install
# ou
pnpm install
# ou
bun install

3. Iniciar o servidor de desenvolvimento

npm run dev
# ou
yarn dev
# ou
pnpm dev
# ou
bun dev

```
